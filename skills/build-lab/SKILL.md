# Выполнение лабораторной

Сверь задание и критерии с текущими файлами проекта. Установи, что уже сделано, какие пункты остались и какую среду нужно использовать: локальный код, СУБД, VM или другое окружение.

- Работай в существующей структуре и стиле проекта. Не добавляй эксперименты, библиотеки, графики или инфраструктуру только ради объёма работы.
- Проверь ключевые свойства решения запуском, тестами, запросами или командами в доступной среде. Разделяй наблюдавшийся результат и ожидаемое поведение. Для проверки на машине пользователя дай воспроизводимые команды и укажи нужный вывод.
- Для VM и сервисов фиксируй реальные версии, роли узлов, настройки и команды проверки. Не утверждай, что лабораторная завершена, пока обязательные действия не выполнены.
- Для Java предпочитай стандартные возможности языка, когда они делают решение понятнее; не заменяй читаемый код Stream API автоматически. В комментариях объясняй только нетривиальную логику и сохраняй стиль проекта.
- Краткий README к лабораторной должен объяснять запуск, входные данные и расположение результата. Подробности добавляй, если они нужны для воспроизведения.

После выполнения перечисли покрытые пункты задания и оставшиеся ограничения. Для подготовки показа преподавателю используй `prepare-defense`.
