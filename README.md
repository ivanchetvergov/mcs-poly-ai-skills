# MCS Poly AI skills

Скиллы для учебных задач МКС Политеха. Каждый скилл находится в собственной папке `skills/<name>/` и содержит `SKILL.md`; дополнительные правила и материалы лежат рядом в `references/`, `scripts/` или `assets/`.

## Скиллы

| Скилл | Назначение |
| --- | --- |
| [academic-report](skills/academic-report/SKILL.md) | Подготовка, доработка и проверка учебных отчётов в LaTeX с учётом требований дисциплины и преподавателя. |
| [technical-latex-report](skills/technical-latex-report/SKILL.md) | Подробный процесс подготовки технического отчёта: математика, реализация, эксперименты и проверка PDF. |

Подключайте нужную папку скилла в AI-инструменте, который поддерживает формат `SKILL.md`. `academic-report` содержит правила из приложенных материалов, а `technical-latex-report` перенесён из локального каталога скиллов. При пересечении используйте требования задания и профиля преподавателя из `academic-report`; технические рекомендации второго скилла применяйте там, где они им не противоречат.
