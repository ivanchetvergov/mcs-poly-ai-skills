# Учебные скиллы МКН

Скиллы для задач по направлению «Математика и компьютерные науки». Каждый каталог `skills/<name>/` — отдельный скилл с файлом `SKILL.md`. Подключайте нужные каталоги в инструменте, который поддерживает этот формат.

## Выбор скилла

| Задача | Скилл |
| --- | --- |
| Разобраться в лекции, слайдах или теории | [study-lecture](skills/study-lecture/SKILL.md) |
| Решить или проверить конкретную задачу и вариант | [solve-exercise](skills/solve-exercise/SKILL.md) |
| Реализовать и проверить лабораторную | [build-lab](skills/build-lab/SKILL.md) |
| Подготовить показ и ответы преподавателю | [prepare-defense](skills/prepare-defense/SKILL.md) |
| Написать или существенно доработать LaTeX-отчёт | [academic-report](skills/academic-report/SKILL.md) |
| Проверить и исправить существующий отчёт | [review-report](skills/review-report/SKILL.md) |
| Написать или отредактировать отдельный объясняющий текст | [write-clear-text](skills/write-clear-text/SKILL.md) |

Материалы в `references/` открываются по мере необходимости. Конкретное задание, критерии преподавателя и существующие файлы проекта определяют содержание работы. Скиллы не задают единый шаблон для всех дисциплин.

Прежний `coursework-helper` разделён на скиллы для лекций, задач, лабораторных и защиты. Содержание `technical-latex-report`, полезное для учебных отчётов, перенесено в справочник `academic-report/references/technical-writing.md`; два скилла для написания одного и того же отчёта больше не конкурируют при выборе.
